# 常见坑与规避指南

## 坑1：第一周热情高涨第二周开始抗拒

### 现象
孩子前几天积极打卡、主动完成，新鲜感消退后从第二周开始找借口、拖延、甚至直接拒绝执行。

### 原因
- 启动门槛设太高，孩子用新鲜感的能量硬撑过前几天，消耗完后感到负担
- 家长第一周热情也高，执行严格标准，孩子感到压力
- 缺乏对「热情衰退是正常现象」的预期，家长和孩子的信心同时受挫

### 规避
- **启动期只要求行为发生，不要求质量**：第一周只要做了就给分，哪怕做得不好
- **门槛降到最低**：把「整理房间」拆成「把书放回书架」这种5分钟可完成的动作
- **提前告知家长热情衰退规律**：第二周抗拒是正常的，不代表方案失败，坚持执行即可
- **准备话术**：孩子抗拒时用共情+探索原因，而非强迫（见 `templates/parent-script.md`）
- **灵活降级**：若抗拒持续2天以上，将标准临时降回第一周水平，平稳度过再逐步回升

## 坑2：积分逐渐失效

### 现象
曾经有效的积分激励越来越难激发动力，孩子开始敷衍完成或对兑换池表示「没意思」。

### 原因
- 兑换池长期不更新，孩子对已有奖励产生饱和（边际效用递减）
- 奖励与孩子当前兴趣脱节（孩子兴趣变化快，3个月前的奖励已不吸引）
- 积分获取过于容易或过于困难，失去激励张力
- 过度依赖外在奖励，未及时向内在动机过渡

### 规避
- **每2-3周与孩子协商更新兑换池**：淘汰失去吸引力的旧选项，加入新选项
- **观察孩子近期兴趣变化**：将奖励与当前兴趣挂钩（如孩子最近迷恐龙，中期奖励可设恐龙博物馆）
- **调整积分难度曲线**：太容易则提高标准，太难则拆分步骤
- **及时进入维持期**：当外在奖励出现疲劳信号时，减少给分频率，增加对行为本身益处的讨论
- **警惕过度理由效应**：出现「做了这个能得几分」的提问时，说明动机已外移，需强化内在动机

## 坑3：多习惯并行导致孩子应接不暇

### 现象
同时启动3个以上习惯打卡，孩子前几天全部完成，一周后开始选择性放弃，最终全部崩盘。

### 原因
- 认知负荷过载：孩子需要同时记住多个习惯的执行时机和标准
- 注意力分散：家长忙于追踪多个打卡项，每个都顾不过来
- 缺乏优先级：所有习惯平等对待，没有主次之分
- 新旧混在一起：旧习惯还没稳固就加新习惯，互相干扰

### 规避
- **同时追踪不超过3个**：根据孩子年龄，3-6岁最多2个，6岁以上不超过3个
- **优先级排序**：核心习惯（如按时作业）>辅助习惯（如整理书包），核心优先启动
- **习惯叠加**：将辅助习惯绑定到核心习惯之后执行，减少记忆负担
- **新旧搭配**：新习惯启动时，旧习惯进入维持期（减少奖励频率），把注意力集中在新习惯上
- **错峰启动**：不要同一天启动多个新习惯，间隔3-5天逐个加入

## 坑4：家长执行不一致导致体系崩溃

### 现象
有时给分有时忘给，标准时松时紧，心情好时严格、忙碌时放水，孩子开始钻空子或对规则失去信任。

### 原因
- 家长自身未形成稳定的执行习惯
- 家庭成员标准不统一（妈妈严格、爸爸放水）
- 忙碌时无暇打卡，规则执行断断续续
- 没有固定的打卡时间和工具，容易遗忘

### 规避
- **固定每日打卡时间**：如每晚睡前5分钟统一盘点当天完成情况
- **家庭成员统一标准**：启动前所有照护者（父母/祖辈）协商一致，制定书面规则
- **至少连续执行2周不调整规则**：频繁修改规则会让孩子感到混乱
- **使用可视化工具**：贴纸板/打卡表放在显眼位置，降低遗忘概率
- **家长自查**：使用以下自查清单定期回顾

## 家长执行一致性自查清单

回答以下5个问题，任一答「否」即需调整：

1. **过去7天中，有几天忘记给孩子打卡或给分？**
   - 超过2天 → 固定打卡时间，设置手机提醒

2. **家庭成员（含祖辈/保姆）对积分规则和标准的理解是否一致？**
   - 不一致 → 召开家庭会议，书面记录统一规则并告知所有照护者

3. **过去2周内是否因心情或忙碌临时改变过标准（如某天降低完成门槛）？**
   - 是 → 恢复原标准，坚持至少2周不随意调整

4. **孩子是否能清楚说出当前规则和兑换标准？**
   - 不能 → 规则可能过于复杂或不稳定，简化并固定

5. **是否在执行过程中频繁增加新规则或修改旧规则？**
   - 是 → 冻结当前规则2周，积累数据后再评估是否调整

## 过度奖励警示信号

以下3个信号出现任一，说明外在奖励已过度，需进入维持期策略：

1. **动机外移信号**：孩子开始在做任何事前问「做了这个能得几分」——说明行为动机已从内在转向外在
2. **奖励消失即行为消失**：暂停一天积分后，孩子立刻不愿执行——说明未形成内在驱动，过度依赖外部强化
3. **奖励阈值持续上升**：孩子对原有奖励表示「没意思」，要求更大更多——说明边际效用递减，需减少外部奖励频率并转向内在动机培养
